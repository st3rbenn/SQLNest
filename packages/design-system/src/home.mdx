# SQLNest Design System
Bienvenue sur la documentation du Design System de SQLNest.

## Introduction
Le Design System de SQLNest est une collection de composants réutilisables, de styles et de directives visant à assurer une cohérence visuelle et fonctionnelle à travers toutes les applications et plateformes de SQLNest. Il est conçu pour faciliter le développement rapide et efficace tout en maintenant une expérience utilisateur de haute qualité.

## Librairies Utilisées
Le Design System de SQLNest est construit en utilisant les technologies suivantes :
- **React** : Pour la création de composants UI réutilisables.
- **TypeScript** : Pour une typage statique et une meilleure maintenabilité du
- **Mantine** : Pour les composants UI et les styles.
- **Storybook** : Pour la documentation et le développement isolé des composants.
- **MDX** : Pour la documentation enrichie avec du Markdown et des composants React.

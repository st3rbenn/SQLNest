# `@sqlnest/frontend`

Application web de SQLNest : React, TanStack Router et Query, Mantine, CodeMirror, Vite.

```bash
pnpm --filter @sqlnest/frontend dev
```

Écoute sur `http://localhost:3000` et appelle le backend sur `http://localhost:4000`. Voir le [README racine](../../README.md) pour démarrer l'ensemble.

| Commande | Rôle |
|-|-|
| `pnpm --filter @sqlnest/frontend type-check` | Types |
| `pnpm --filter @sqlnest/frontend test` | Tests unitaires |
| `pnpm --filter @sqlnest/frontend build` | Types puis bundle de production |
